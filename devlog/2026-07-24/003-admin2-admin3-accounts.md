## 작업 요약
기존 RBAC 기반 총괄·상품·주문 관리자 권한과 역할별 운영 화면을 유지하면서 기본 관리자 계정 ID를 요청한 체계로 정리했습니다.
현재 운영 DB에는 `admin2` 상품관리자와 `admin3` 주문관리자 계정을 생성하고, 비밀번호를 bcrypt 해시로 저장했습니다.

## 남은 리스크
- 초기 관리자 비밀번호는 추측하기 쉬운 값으로 설정하지 말고, 총괄관리자 화면에서 반드시 강한 비밀번호로 관리해야 합니다.
- 현재 DB 외의 신규 배포 환경에서는 `MARKET_ADMIN2_PASSWORD`, `MARKET_ADMIN3_PASSWORD` 환경변수를 설정해야 기본 계정이 생성됩니다.
- 관리자 운영 화면의 상품·주문 데이터는 기존과 같이 프런트엔드 데모 데이터이며, 영속 API 연결 시 서버 RBAC 검사를 동일하게 적용해야 합니다.
